# Elmurod aka

Create a FULL PROFESSIONAL furniture website for a furniture manufacturing and sales business.

PROJECT TYPE:
- Full-featured commercial website (not a demo)
- Modern, clean, premium UI
- Mobile-first, responsive on all devices
- Focus on product catalog and lead generation

DESIGN STYLE:
- Minimalist, modern, premium
- Soft neutral colors (light gray, beige, dark wood)
- Rounded cards, soft shadows
- High-quality furniture lifestyle images
- Large hero banners and clear typography

STRUCTURE & PAGES:
1. Home page
2. Product Catalog page
3. Product Details page
4. About Us page
5. Contact page
6. FAQ page
7. Admin-ready structure

HOME PAGE SECTIONS:
- Hero section with large furniture image, headline, subheadline and CTA button "View Catalog"
- Benefits section with icons (Custom order, Fast delivery, Warranty, Quality materials, Free consultation)
- Featured Products section (grid cards with image, name, price, rating)
- Category banners (Kitchen, Bedroom, Living Room, Office furniture)
- Promotion / Special Offers banner
- Customer reviews section
- Footer with contact info, social links and WhatsApp button

PRODUCT CATALOG:
- Grid layout
- Filters: category, price range, material, room type
- Search bar
- Pagination or infinite scroll

PRODUCT DETAILS PAGE:
- Image gallery (multiple images)
- Product name, price
- Short description + full description
- Material, size, color options
- CTA buttons: "Order via WhatsApp" and "Request consultation"

ADMIN & CONTENT:
- Admin-friendly editable content
- Dynamic product data
- Easy product add/edit/delete
- Multi-language ready (UZ / RU)
- SEO optimized structure

INTEGRATIONS:
- WhatsApp floating button
- Telegram contact link
- Contact form with validation

PERFORMANCE & TECH:
- Fast loading
- SEO friendly
- Clean semantic HTML structure
- Ready for backend integration later (Supabase compatible)

LANGUAGE:
- Default language: Uzbek
- Second language: Russian
- Text placeholders in both languages

FINAL GOAL:
- Professional furniture website that looks like a real commercial brand
- Ready to be used for sales, not just a template
